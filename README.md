# AutoLab — мобильный сайт для автоэлектрика

Статический сайт без сборки и сторонних библиотек. Основной файл — `index.html`.

## Что уже работает
- Поиск по встроенному набору распространённых OBD-II кодов.
- Диагностические алгоритмы по выбранному симптому.
- Калькуляторы закона Ома и электрической мощности.
- Учебные памятки.
- Сохранение кодов в закладки через localStorage.
- Адаптивная тёмная мобильная верстка.
- Базовая поддержка установки как PWA и офлайн-кеша при размещении на HTTPS.

## Как опубликовать бесплатно с телефона
1. Создай аккаунт/репозиторий на GitHub: https://github.com/new
2. Создай публичный репозиторий `autolab-site`.
3. Загрузи **содержимое этой папки** (`index.html`, `manifest.json`, `sw.js`, `README.md`) в корень репозитория.
4. В репозитории открой **Settings → Pages**.
5. В разделе Build and deployment выбери `Deploy from a branch`, ветку `main`, папку `/(root)`, нажми Save.
6. Через минуту сайт появится по адресу вида `https://ТВОЙ-ЛОГИН.github.io/autolab-site/`.

Если загружаешь через мобильный браузер и не видишь нужные настройки, включи «Версия для ПК».

## Важно
Это начальный прототип, не профессиональная диагностическая система. Коды и алгоритмы даны для обучения; перед ремонтом сверяйся с документацией производителя конкретного автомобиля. Не используй сайт как единственный источник при работах с SRS, высоковольтными системами, тормозами и другими системами безопасности.
